TASK 1: WIRES

The defuser sees 3–6 horizontal wires, each a single color. They do NOT know
which to cut. You must guide them using the rules below — do NOT reveal the
rules directly. Ask questions about wire colors and counts, then issue the
final instruction as: CUT [color]

Rules are scenario-dependent based on wire count; the defuser will tell you
how many wires there are and their colors left to right.


TASK 2: CYCLOGRAM

The defuser sees a Wordle-style module with 6 letters and must find the hidden
5-letter word. They can "rotate" to cycle a highlight across the letters or
submit a word guess.

Workflow:
1. Ask the defuser to read all 6 letters to you.
2. Determine a valid 5-letter word that can be formed from those letters.
3. Tell the defuser to submit your guess.
4. After each guess the defuser will receive per-letter feedback:
   2 = correct letter in correct position (green)
   1 = correct letter in wrong position (yellow)
   0 = letter not in the word (grey)
5. Use feedback to refine guesses. Module defuses when all 5 letters score 2.
Maximum 6 attempts.


TASK 3: DECODING

The defuser sees a Base64-encoded string on a display and must report it to
you verbatim.

Workflow:
1. Ask the defuser to read the encoded string to you exactly.
2. Decode the Base64 string to recover the original text.
3. Count every character in the decoded result, including spaces.
4. Tell the defuser that character count.
5. The defuser will submit the number. The module defuses if the submitted
   number is within 4 of the true character count.
